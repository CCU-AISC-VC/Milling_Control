# 2026-10-22 路線圖：FANUC 機器人銑削模擬與 sim2real 平台

目標：讀入工件 G-code，轉成 FANUC M-710iD/70 ＋ 主軸的關節軌跡；同一份軌跡在 Newton 模擬（Isaac Sim RTX 渲染）與真機上執行；之後擴充到兩台 M-710iD/70 協同加工。

```
G-code 檔
  → 解析成工具路徑段（G0/G1/G2/G3、進給、主軸轉速、工件座標）
  → 依弦差與進給率取樣成「時間 + TCP 位姿」序列（program → base_link）
  → 批次 IK 轉成關節軌跡（極限、奇異點、連續性檢查）
  → 同一份軌跡檔同時餵給：
       (a) Newton 模擬（碰撞、追蹤誤差）＋ Isaac Sim RTX 渲染
       (b) ROS 2 bridge → fanuc_ros2_driver 的 follow_joint_trajectory
```

## 使用者 2026-10-22 的決定

1. G-code 由本專案自己生成、自己測試（沒有現成的 CAM 輸出檔）。
2. 第二台機器人也是 M-710iD/70。
3. 主軸 TCP 與工件位置沿用既有 xacro 的值，SPEC 標 ⚠️ UNVERIFIED。
4. 既有 ROS 2 工作區搬到 `ros2_ws/src/`，`build/install/log` 不進 git。
5. 材料移除（M5）留到之後。

| M0 環境與資產 | repo 骨架與文件；xacro 攤成 URDF；Newton 載入；FK 對照 | `outputs/m0_assets/`：FK 對照 CSV、誤差圖、TCP 樣本圖、快照 | 1000 組隨機關節角，Newton 與 NumPy FK 的 TCP 位置差 < 0.01 mm | ✅ 2026-10-22（最大 0.0010 mm） |
